# BACnet Simulator + QA Harness

Two things in one repo:
1. **A BACnet/IP device simulator** (Python / bacpypes) that serves realistic device
   behaviours — aborts, constrained APDUs, oversized arrays, slow responses, TSM
   pressure — so the **Connectware 2.x BACnet adapter** (polling-only: ReadProperty +
   indexed/ReadRange array recovery) can be tested without real hardware.
2. **The QA harness** that drives the adapter against those sims end-to-end: deploy
   SCFs to Connectware → read the data back over MQTT → assert integrity.

The repo **root is the simulator** (a standard Python + Docker project); the QA
harness lives entirely under **`qa/`** and all reference docs under **`docs/`**.

### Sim fleets (`compose/`)

The base fleet is `compose.yaml` at the root (`docker compose up`); the rest live in
`compose/` and are started with `docker compose -f compose/<name>.compose.yaml up`.

| Compose | Brings up | Used by |
|---|---|---|
| `compose.yaml` *(root)* | the base fleet (modern, legacy, miele, ultra-slow, …) | Steps 2–4, qa-trio |
| `compose/huge.compose.yaml` | `bacnet-huge` (1001-object device) | `func-array-e2e` |
| `compose/largescale.compose.yaml` | `bacnet-mega-b` (20k object-list) | `discovery-e2e`, P2 |
| `compose/mega` + `compose/bigarray` | extra large-array peers | P2 (mega-scale) |
| `compose/scale-fleet` + `compose/miele-fleet` | the 32-device read-soak fleet | `scale-soak-e2e` (generated by `gen-scale-fleet.sh`) |
| `compose/rw-fleet.compose.yaml` | writable round-trip devices | `rw-soak-e2e` (generated by `gen-rw-fleet.sh`) |
| `compose/reconnect.compose.yaml` | `bacnet-reconnect-target` | `lifecycle-e2e` / P4 |
| `compose/weatherstation` + `compose/ws-overload` | WeatherStation devices | P8 / `ws-*-soak` |
| `compose/bbmd.compose.yaml` | BBMD loopback sink | manual BBMD checks |
| `compose/miele-real.compose.yaml` | `bacnet-miele-real` | qa-trio `miele-production-test` (Step 3) |

## Run the simulator

```bash
docker compose up --build          # all base devices, host network
docker compose up bacnet-modern    # a single device
docker compose logs -f             # follow logs
```

Each device's port, instance and behaviour come from its profile in
`profiles-cybus/` (extending `profiles/_base.yaml`) — see [docs/PROFILES.md](docs/PROFILES.md).

## Environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `BACNET_PORT` | 47808 | UDP listen port |
| `BACNET_BASE_DEVICE_ID` | 100 | BACnet device instance ID |
| `BACNET_PROFILES_DIR` | profiles | Profile YAML directory |
| `BACNET_BIND_ADDRESS` | 0.0.0.0 | UDP bind address |
| `BACNET_LOG_LEVEL` | INFO | DEBUG shows every APDU on the wire |
| `BACNET_LOG_FORMAT` | text | `text` or `json` |
| `BACNET_METRICS_PORT` | 9100 | Prometheus `/metrics` port |
| `BACNET_OBJECT_PADDING` | 0 | Extra objects for NewLift scaling (see [docs/PROFILES.md](docs/PROFILES.md)) |
